# Day 03：Router、Pinia 和 Axios

## 当前状态

未开始。

## 练习目标

增加登录页和用户信息页，使用本地模拟数据跑通以下流程：

```text
用户填写登录信息
    ↓
提交登录
    ↓
Pinia 保存登录状态
    ↓
路由跳转到用户信息页
    ↓
刷新页面后恢复状态
```

## 计划复习内容

| 内容            | 练习中的用途                         |
| --------------- | ------------------------------------ |
| Vue Router      | 配置登录页、用户信息页和页面跳转     |
| Pinia           | 保存用户信息和登录状态               |
| Axios           | 调用本地模拟登录接口                 |
| 加载状态        | 提交登录时禁用按钮或显示加载提示     |
| 失败提示        | 模拟登录失败时向用户显示原因         |
| TypeScript 接口 | 定义登录请求、登录响应和用户信息类型 |
